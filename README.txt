STILLWATER — INTERACTIVE AQUARIUM

Windows 11 setup
1. Install the free Lively Wallpaper app from https://www.rocksdanister.com/lively/
2. Extract this ZIP to a permanent folder, e.g. Pictures\Stillwater.
3. Open Lively, choose Add Wallpaper / Choose a file, and select index.html.
4. Select the imported wallpaper to apply it to your desktop.
5. Right-click its tile and choose Customize Wallpaper to change fish count,
   swimming speed, lighting, frame rate, and cursor attraction.

You can also open index.html directly in Edge or Chrome for a browser preview.
The HTML works fully offline and has no dependencies or external requests.

Interaction
- Move your pointer over the desktop to attract nearby fish.
- Left-click empty desktop space to drop food. Fish swim toward and eat it.
- The introductory text fades after a few seconds.
- In a browser, hover at top right for Settings.
- In Lively, use Customize Wallpaper if its input mode does not pass clicks.
  Check Lively's wallpaper input settings if mouse interaction is disabled.
  Desktop icons and open windows can intercept clicks.

Performance
- Default: 22 fish at 30 fps. Choose 60 fps for smoother movement.
- Rendering resolution is capped at 2560 pixels wide to control GPU load.
- Works with widescreen, ultrawide and portrait aspect ratios.
- Configure Lively's Performance options to pause wallpapers during fullscreen
  apps and on battery if desired. No audio plays.
- Lively property values are authoritative on wallpaper startup; browser
  settings are stored locally where the browser permits localStorage.

This package includes editable source code. No installer or admin script needed.
Canvas rendering and simulation logic verified using a Node Canvas harness.
Browser interaction and Windows desktop hosting have not been verified here.
