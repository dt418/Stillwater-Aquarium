Stillwater adaptation: Windows/Lively controls, high-refresh frame rate options,
measured cadence HUD, offline classic-script build with embedded textures,
render scale controls and pixel cap, high-performance fluid rendering profile,
startup/error handling and high-refresh regression checks.

The upstream macOS app and installer are not included. This package uses Lively
as the Windows wallpaper host. The scene meshes and artwork come from the upstream
project and its listed texture sources; they are not claimed as original Stillwater art.
